# MotionVideo-by-Sujan

Resources, prompts, and Remotion skills for creating Bangla and English motion graphics videos from voiceover SRT scripts.

## Contents

- `prompt.md` — Workflow instructions for generating Remotion motion graphics compositions from voiceover `.srt` files (scene planning, color scheme selection, offline fonts, SFX, and frame verification).
- `Bornomala-Regular.ttf` — Bangla font file for offline rendering in Remotion.
- `prodhan_remotion_graphics.skill` — Base Remotion motion graphics skill package.
- `prodhan_remotion_graphics_v2_super_energy.skill` — V2 super-energy motion graphics skill package.
- `super-explainer-motion-graphics_by_prodhan_v3.skill` — V3 super-explainer motion graphics skill package.

## Usage

1. Load one of the `.skill` packages in your AI coding assistant.
2. Follow the workflow in `prompt.md` and provide a voiceover `.srt` file (along with optional logo/assets and resolution preferences).
3. Use `Bornomala-Regular.ttf` for rendering Bangla typography cleanly in Remotion Studio.
